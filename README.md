# Sala Fácil

Site responsivo para organizar tarefas escolares e guardar questões/anotações de estudo.

## Recursos
- Cadastro de tarefas com matéria, prazo e observações.
- Filtros para todas, pendentes ou concluídas.
- Indicadores de tarefas totais, pendentes e concluídas.
- Caderno de questões com tentativa/resposta.
- Armazenamento local no navegador (localStorage).
- Exportação dos dados em JSON.
- Interface adaptável a celulares e computadores.

## Executar
Abra `index.html` no navegador. Não é necessário instalar dependências.

## Publicar no GitHub Pages
1. Abra **Settings → Pages**.
2. Em **Build and deployment**, escolha **Deploy from a branch**.
3. Selecione `main` e `/(root)`, depois clique em **Save**.
4. Aguarde a publicação e abra o endereço que o GitHub mostrar.

## Privacidade e limites
Este projeto é independente e não acessa a conta da Sala do Futuro nem envia atividades automaticamente. Os dados ficam no navegador atual; use **Exportar meus dados** para backup. Não coloque senhas ou tokens no repositório.
